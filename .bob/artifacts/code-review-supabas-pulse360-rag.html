vector_literal() produces raw SQL string, bypassing parameterization
supabase_store.py:27

Security vector_literal() builds a raw string like [0.123,…] passed as a %s parameter. validate_vectors() runs beforehand and the format string is controlled, but this pattern bypasses the normal SQL parameterization safety net and requires a standing comment to keep reviewers informed.

Recommended fix

Register the pgvector type adapter via psycopg3's adapt() so the list passes as a typed parameter, or add a prominent comment above every call-site confirming validate_vectors() is the explicit safety gate.

Section regex produces false positives on all-caps content
chunker.py:6

Correctness SECTION_RE second alternative matches any 4+ uppercase line — FAQ list items, table headers, acronyms (N/A:, URL:) all match, causing incorrect section splits that break chunk context and hurt retrieval quality.

Recommended fix

Require the non-markdown alternative to end with : (making it an explicit label) or add a minimum word count. Alternatively restrict section detection to markdown headers only (#{1,3}\s+).

10
Sliding window can advance by 1 character on large overlap values
chunker.py:86

Performance start = max(start + 1, end - overlap_chars) — if overlap_chars approaches max_chars, the window advances by 1 character per iteration. On a large text section this produces millions of near-duplicate chunks and effectively hangs ingestion.

Recommended fix
start = max(end - overlap_chars, start + max(1, overlap_chars // 2))
11
Chroma cosine distance → similarity conversion is wrong
vector_store.py:179

Correctness Note: vector_store.py was deleted in the Supabase-only refactor. If Chroma is ever re-introduced as an adapter, this bug must not be carried forward: Chroma returns cosine distance in [0, 2]; 1.0 - distance can produce negative scores.

Correct conversion
score = max(0.0, 1.0 - distance / 2.0)

13
No rate limiting on /search and /ask endpoints
api/routes.py:88

Security / Ops Both endpoints accept unlimited requests per client. A single client can saturate the HuggingFace embedding quota or LLM token budget. No per-IP throttle or circuit breaker is in place.

Recommended fix

Add slowapi middleware for per-IP rate limiting. Propagate the existing request_id as an X-Request-Id response header so it can be correlated across Pulse360 logs and this API's Vercel logs.

14
New SupabaseLibrary instantiated on every search request
retriever.py:17

Performance SupabaseLibrary(settings).search(…) constructs a new object on every call, re-importing psycopg and resolving the connection string each time. Under Vercel's serverless model each invocation may be a cold start anyway, but within a warm instance this adds unnecessary per-request overhead.

Recommended fix

Inject a shared SupabaseLibrary instance via FastAPI's Depends(), matching the pattern already used in api/documents.py via get_library().
